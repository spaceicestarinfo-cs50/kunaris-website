# Chinese typography notes

This project does not bundle or redistribute commercial/proprietary font files.

Preferred Chinese web font families in CSS:
- Noto Serif CJK SC — SIL Open Font License 1.1
- Noto Sans CJK SC — SIL Open Font License 1.1
- Source Han Serif SC / Source Han Sans SC — SIL Open Font License 1.1

The CSS also includes common operating-system Chinese fonts as local fallbacks only. Those font files are not included in this project.

No Google Fonts network request is used.
