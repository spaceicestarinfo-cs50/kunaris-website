# Kunaris Website

Initial Next.js homepage prototype for Kunaris Education & Media Inc.

## Run locally

1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

This V1 intentionally keeps the homepage simple: brand first, then the two primary pathways — FOR YOU and FOR YOUR BUSINESS.
